네오봇 수학SW체험 — 사용법 (폴더판, 2026.10.6.)

[처음 한 번] (인터넷 필요 없음)
1. 이 폴더를 노트북 아무 곳에나 복사 (예: 문서, 바탕화면)
2. 처음설치.bat 더블클릭
   → 동글 드라이버 압축 풀기 → 설치(관리자 창에서 [예], 설치 창에서 다음·마침) → 바탕화면 '네오봇 SW체험' 아이콘
   - 관리자 권한이 막힌 노트북은 드라이버 설치가 안 됨 → 정보 담당 선생님께 부탁
   - 처음설치.bat이 안 되면 직접: [NEOPIA]dongle driver.zip 압축 풀기 → [Install]dongle driver.exe 실행 → Make-Desktop-Shortcut.bat 실행
3. 확인: 동글 꽂기 → 아이콘 실행 → [로봇 연결] 목록에 CP210x가 보이면 설치 끝

[매번]
1. 동글 꽂기 → 로봇 전원 켜기(① Coding 모드)
2. '네오봇 SW체험' 아이콘(또는 Run.bat) 실행
3. 오른쪽 위 [로봇 연결] → CP210x 포트 선택 (한 번 허용하면 다음부터 자동)
4. 연결되면 로봇이 '삐' 3번 + 불 깜박임 → 내 로봇이 맞는지 확인
   (다시 확인: 오른쪽 위 [내 로봇 확인] 버튼)

[교실에서 여러 대]
- 동글과 로봇에 같은 번호 붙이기, 수업 전 한 세트씩 켜서 짝 확인
- 내 로봇이 아닌 로봇이 반응하면 → 전원 끄고 선생님 부르기
- 수업 중 노트북·로봇 바꾸지 않기 (바퀴 방향·똑바로 가기·출발 보정 값이 노트북에 저장됨)
- 바꿨다면 미션 ① 조립 [바퀴 시험], ② 한 바퀴 [4번 나눠 돌기] 다시

[주의]
- 엔트리 하드웨어 연결 프로그램이 켜져 있으면 연결 안 됨 → 먼저 종료
- 인터넷 없이 동작 (3D 조립도 포함). 반드시 Run.bat으로 실행 (index.html 직접 열면 3D 조립도가 그림으로 바뀜)
- 엣지(윈도우 기본) 또는 크롬 필요
- 로봇이 반응 없으면: 처음 화면 아래 [연결 점검]
- 아이콘을 눌러도 앱 창이 안 뜨고 평소 엣지만 열리면: Run.bat을 직접 실행, 그래도 안 되면 폴더 안 launch-log.txt 내용 확인(브라우저 위치·주소가 적혀 있음)
- 다음 반이 같은 노트북을 쓸 때: 미션 화면 [기록] → [다음 모둠 시작]
- 블록코딩 작품은 이 노트북에 자동 저장, 다른 PC로 옮길 땐 '파일로 저장'
